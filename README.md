# تحلیل دمای تهران
## Tehran's Temperature Analyzer

این پروژه یک ابزار ساده برای تولید و تحلیل داده‌های دمایی شهر تهران است.  
هدف اصلی این است که با اجرای یک فایل، یک مجموعه داده مصنوعی ساخته شود و سپس شاخص‌های آماری مهم روی آن محاسبه و نمایش داده شود.

---

## ساختار پروژه

پروژه از سه فایل پایتون تشکیل شده است که هر کدام وظیفه مشخصی دارند.

### `dataset_maker.py`

ساخت مجموعه داده را بر عهده دارد.

- با استفاده از `random.normal` مقادیر دمایی را به‌صورت تصادفی تولید می‌کند.
- میانگین توزیع: `30`
- انحراف معیار: `5`
- تعداد نمونه‌ها: `365` (دمای هر روز از یک سال)
- تاریخ‌ها: از اول ژانویه 2025 تا اول ژانویه 2026
- خروجی: ذخیره داده‌ها در فایل `Tehran_tmps_dataset.csv`

### `calculate.py`

شامل توابع محاسباتی و رسم نمودار است. این توابع عبارت‌اند از:

| نام تابع | توضیحات |
|----------|---------|
| `scale` | محاسبه انحراف معیار و واریانس. اگر آرگومان دوم `True` باشد واریانس برگردانده می‌شود، در غیر این صورت جذر واریانس (انحراف معیار) بازگردانده می‌شود. |
| `maxim` | بیشترین دما را برمی‌گرداند. |
| `minim` | کمترین دما را برمی‌گرداند. |
| `loc` | میانگین دما را محاسبه می‌کند. |
| `vector` | نمودار خطی دما را بر حسب روز رسم می‌کند. |
| `histogram` | یک هیستوگرام از داده‌ها تولید می‌کند. تعداد سطل‌ها بر اساس جذر تعداد نمونه‌ها تعیین می‌شود. |
| `describe` | تمام مراحل بالا را روی یک فایل CSV اجرا می‌کند، نتایج را چاپ کرده و سپس نمودارها را نمایش می‌دهد. |

### `run.py`

نقطه شروع اجرای برنامه است.

- ابتدا تلاش می‌کند فایل داده را بخواند و تحلیل کند.
- اگر فایل وجود نداشته باشد، آن را می‌سازد و سپس تحلیل را انجام می‌دهد.

---

## نحوه اجرا

برای اجرای برنامه کافی است دستور زیر را در ترمینال وارد کنید:

```bash
python run.py
```

- اگر فایل داده از قبل وجود داشته باشد، فقط تحلیل انجام می‌شود.
- در غیر این صورت، ابتدا داده ساخته شده و سپس تحلیل صورت می‌گیرد.
